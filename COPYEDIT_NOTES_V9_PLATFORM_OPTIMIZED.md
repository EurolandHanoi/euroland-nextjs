# V9 platform hero optimisation

This version optimises the Platform overview top section after the V8 layout felt visually heavy.

## What changed

- Combined the separate “Why Euroland IR” and “Platform” hero blocks into one coherent hero section.
- Put “Why Euroland IR” at the top as the eyebrow label.
- Kept the main headline: “Built for investor relations teams”.
- Kept the managed-platform positioning directly under the headline.
- Kept the Book a Demo and Contact Us CTAs centred.
- Moved the four value cards into the same hero area, below the CTA, instead of creating a second competing section.
- Shortened the card body copy to improve visual balance and scannability.
- Left the rest of the Platform page structure unchanged.

## Rationale

This avoids stacking two large hero-style sections on top of each other while still giving “Why Euroland IR” primary placement. The page now opens with a single, centred, premium corporate introduction followed by concise supporting proof cards.
